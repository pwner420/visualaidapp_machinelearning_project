1. Open terminal in directory
2. download dataset with commands (you can also just download it any other way and place it in the repo):
 wget "https://github.com/awsaf49/flickr-dataset/releases/download/v1.0/flickr8k.zip"
 unzip -q flickr8k.zip -d ./flickr8k
 rm flickr8k.zip
3. Adjust paths in trainer.py as necessary.
4. start training model with command: python trainer.py
5. once weights have been generated, convert to .tflite model with command: python converter.py
6. when you have your .tflite model, place it in the assets folder in the app files.
7. open the app project in android studio and run on an emulated device or make a .apk file to run on an actual phone. (give camera permissions to the app!)
